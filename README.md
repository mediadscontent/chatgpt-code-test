# Sparkle Salon

Mobile makeover game preview. Open index.html on GitHub Pages or another static HTTPS host.

- 7 interactive makeover tasks and 8 visual progression frames
- Compressed WebP atlas (approximately 43 KB)
- Hair-detangling targets on exposed hair (not headband)
- Touch drag / hold actions with screen-scroll suppression
- 30-level progression, saved locally

GitHub branch: sparkle-salon. This is a playable web preview; not a TikTok Native release.
